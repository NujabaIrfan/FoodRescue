# 🍲 FoodRescue

**FoodRescue** is a community-driven platform designed to **rescue surplus food** and redistribute it to those in need.  
By connecting **restaurants, grocery stores, and individuals** with **charities and food banks**, FoodRescue helps minimize food waste and promote sustainability.

---

## 🌍 Mission

To create a **zero-waste food ecosystem** where technology bridges the gap between food surplus and hunger relief — ensuring good food reaches those who need it most.

---

## 🚀 Features

### 👨‍🍳 For Donors
- Add available surplus food with details (type, quantity, expiry, pickup time).
- Upload photos of food donations.
- Track donation history and impact.

### 🏠 For Charities / NGOs
- Browse available donations by location or type.
- Request or reserve available food items.
- Manage pickup and delivery confirmations.

### 🚚 For Volunteers
- View nearby pickup requests.
- Accept and complete deliveries.
- Track donation routes using Google Maps.

### ⚙️ General Features
- Firebase Authentication (Email/Password, Google Sign-in)
- Real-time database updates with Firestore
- Cloud Storage for food images
- Firebase Cloud Messaging (notifications)
- Role-based dashboards (Donor, NGO, Volunteer, Admin)
